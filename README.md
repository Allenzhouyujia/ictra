# ICTRA — research site

Static site for the ICTRA project (WAICY 2026): seizure detection from behind-the-ear EEG, ECG, EMG and movement, trained on SeizeIT2.

- Pages: `index.html` (overview) · `background.html` · `science.html` · `system.html` · `evidence.html` · `safety.html` · `team.html`
- No build step. Deployed on Vercel as a static site (`vercel.json`).
- Results on the Evidence page are development-set numbers until the locked test in November 2026; every version is listed with its accept/reject decision.

Student research prototype. Not a medical device.
